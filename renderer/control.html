How to use TarkovMap

Everything on one page.

1 · What it is and what it is not

TarkovMap reads two things the game writes to your own PC: the log files in the EFT folder (which map, when the raid started, quest started/finished) and the names of in-game screenshots, which the game stamps with your position and facing. From those it draws a live minimap, a full map, quest objectives, extract distances and, for friends who also run it, their positions. It never reads game memory, never injects anything, and never shows enemies.

2 · First run in five steps

  1. Setup ▸ Game: the EFT folder is detected from Steam or the BSG launcher. Fix it if wrong.
  2. In EFT ▸ Settings ▸ Controls, bind Screenshot to the key shown in Setup ▸ Position feed (default F11).
  3. Pick a mode: Hold (hold Caps Lock in raid and the dot streams), Auto (every 2 s in raid) or Manual.
  4. Press Test, go into a raid (offline works), tap the screenshot key once. The test shows your coordinates.
  5. Save. The overlay appears on your main screen; the full map on the second one if you have it.

3 · Hotkeys

  • F7 / F8 map opacity down / up
  • F9 make the overlay clickable (again to hand the mouse back)
  • F10 hide / show the overlay
  • F6 drop a "regroup" ping at your position for the squad
  • Caps Lock (changeable) hold to stream your position

4 · The overlay

The minimap sits in the corner you choose and turns with you (heading-up) so "ahead" is always up. Rings mark 50 and 100 m. Next to it: quests on this map with the trader's portrait and the distance, extracts and teammates sorted by distance with a direction glyph, and the raid line with the timer. It is click-through in raid, so it never eats a click meant for the game. All sizes and opacities live on the Raid page.

5 · The full map

Opens on the second monitor (or with the "Open full map" button). Same tiles and markers, every layer, floors, the flea slider and the ask box. Drag and zoom freely; the minimap is a window onto this map.

6 · Quests

When the game says a quest started, it appears; when the game says it finished, it disappears. Objectives with a fixed spot get a marker with the trader's face. The first run scans your old logs to seed the list. If a quest is stuck, tick it off on the Quests page.

7 · Squad sharing and pings

Everyone types the same squad code and their name. On the same network the app finds the others by itself; positions are shared only inside the same raid. Teammates show on both maps and as a small name tag in the game view (approximate, refreshed with each of your fixes). Pings mark a spot at your position with a word; they show on every squadmate's maps and as a tag, and expire after five minutes.

8 · Layers, flea filter and the ask box

Chips switch layers per map: extracts, quests, places, squad, keys, bosses, scav spawns, hazards, containers, loot, machine guns, switches. The flea slider lights loot spots where an item worth at least that much can spawn (a spawn map, not what actually spawned). The ask box takes a sentence like show extracts, dorm keys and anything over 40k; if the built-in parser doesn't get it and you added an OpenRouter key, a free model translates it.

9 · Fullscreen vs borderless

On Windows 11 a fullscreen EFT normally still shows the overlay thanks to fullscreen optimizations. If you see nothing while the game has focus, either switch EFT to borderless (no performance difference on Windows 11) or use the second-monitor map, which always works.

10 · Privacy, storage and fair play

Screenshots are deleted about a second after they appear; the folder count on the Raid page should read zero. Map tiles are cached once under the data folder (a few hundred MB) and can be cleared. Nothing is uploaded except your squad messages to your own squad and the ask-box sentence to OpenRouter when you enabled it. No enemy positions, no memory reading, no injection.

11 · Troubleshooting

  • No fix: the screenshot key is not bound in EFT, or the mode is Manual. Press Test and tap the key.
  • Wrong map / "in menu" forever: the EFT folder path is wrong; check that build\Logs exists inside it.
  • Overlay invisible: see section 9. Press F10 once in case it was hidden.
  • Teammates missing: same squad code, same raid, same network; Windows Firewall must allow the app on private networks.
  • Blank map: tiles are still downloading (Setup ▸ Storage) or tarkov.dev is down; it retries hourly.
